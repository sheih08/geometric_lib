# Общее описание решения

Проект содержит 4 функции на Python для вычисления площади и периметра геометрических фигур.

## Структура проекта

* `circle.py` — вычисление площади и длины окружности (периметра) круга.
* `square.py` — вычисление площади и периметра квадрата.
* `rectangle.py` — вычисление площади и периметра прямоугольника.
* `triangle.py` — вычисление площади и периметра треугольника.

Все функции задокументированы с описанием параметров, возвращаемых значений и примерами использования.

# Описание функций

## 1. Круг (`circle.py`)

### `area(r)`
Вычисляет площадь круга.
* **Входные параметры**: `r` (`float`) — радиус круга
* **Возвращает**: `float` — площадь круга
* **Пример вызова**:
  ```python
  from circle import area

  print(area(5))  # 78.53981633974483

### `perimeter(r)`
Вычисляет периметр (длину окружности) круга
- **Входные параметры**: `r` (`float`) — радиус круга
- **Возвращает**: `float` — периметр круга
- **Пример вызова**:
  ```python
  from circle import perimeter

  print(perimeter(5))  # 31.41592653589793

## 2. Прямоугольник (`rectangle.py`)

### `area(a, b)`
Вычисляет площадь прямоугольника
- **Входные параметры**: `a` (`float`) — длина, `b` (`float`) — ширина
- **Возвращает**: `float` — площадь прямоугольника
- **Пример вызова**:
  ```python
  from rectangle import area

  print(area(5, 10))  # 50

### `perimeter(a, b)`
Вычисляет периметр прямоугольника

- **Пример вызова**:
  ```python
  from rectangle import perimeter

  print(perimeter(5, 10))  # 30

### `area(a, h)`
